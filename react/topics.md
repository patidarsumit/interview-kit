Why dependency arrays matter

Fragment shorthand vs React.Fragment

App Router vs Pages Router
Server Components vs Client Components
Passing data from Server Components to Client Components
🔹 State Management
Redux vs Zustand
Handling side effects in Redux
Middleware concepts (Thunk, async handling)
🔹 Node.js
How Node.js handles thousands of concurrent requests
Event loop, non-blocking I/O
Scaling strategies and performance optimization
🔹 AWS / CI-CD
Frontend deployment using:
S3
CloudFront
EC2
CI/CD setup and automated deployment strategies
🔹 JavaScript Concepts
Deep copy vs shallow copy
Object/array references

Practical coding + optimization discussions
🔹 AI & Modern Engineering
Questions around LangChain, AI integrations, RAG concepts, and frontend AI workflows
One thing I really liked:

reasoning,
scalability,
optimization,
edge cases,
