# Coupa First-Round Interview Prep

Role focus: Angular 15+, NgRx, WebSockets, SaaS frontend engineering, object-oriented design, design patterns, mentoring, communication, and product mindset.

Use this folder in this order:

1. `company-and-role-research.md` - Coupa context, role signals, and what to emphasize.
2. `questions-and-answers.md` - Main revision file with likely questions and strong answer outlines.
3. `coding-problems.md` - Coding and frontend exercises that match reported Coupa patterns plus this JD.
4. `first-round-plan.md` - Short preparation plan and interview strategy.
5. `sources.md` - Public sources used.

Important note: public Coupa-specific frontend interview data is limited. I separated:

- Reported online: questions/process seen on public interview sites.
- JD-inferred: highly likely because the JD explicitly asks for Angular, NgRx, WebSockets, SaaS, OOP, patterns, and mentoring.
