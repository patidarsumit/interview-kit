completed an Angular Frontend Developer interview today and would like to share the areas that were covered. This was for Siemens L1 with 5+ years of experience required.

**Angular**
- Lifecycle Hooks
- Dependency Injection
- Services
- State Management (RxJS, Subject, BehaviorSubject)
- JWT Authentication & Refresh Tokens
- Standalone Components
- Data Binding
- ViewChild, ContentChild & ElementRef
- Virtual Scrolling
- Dynamic Table Creation using JSON Data

**JavaScript & TypeScript**
- var, let, const
- Event Loop
- Debouncing vs Throttling
- DOM (Document Object Model)
- Asynchronous JavaScript Concepts

**HTML & CSS**
- Flexbox
- CSS Grid
- Responsive Design
- Media Queries
- Bootstrap
- Tailwind CSS

**Git & Development Practices**
- Git Rebase
- Code Reviews
- Debugging Techniques
- Error Handling

**Practical / Coding Round**
- Creating a table from static JSON data
- Rendering data dynamically using Angular templates and *ngFor
- Display total Salary for each department
- Change CSS for rows having a salary greater than 50,000

This experience serves as a good reminder that frontend interviews are rarely just about Angular. Strong fundamentals across JavaScript, CSS, browser concepts, Git, and development practices are equally important.
