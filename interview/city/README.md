# Citi / Citibank Interview Prep - Angular / Frontend Developer

Assumption: "city bank" means Citi / Citibank.

This folder is prepared for Citi / Citibank Angular frontend interviews, from L1 technical screening to L2 technical-managerial or hiring-manager discussion.

## Expected Interview Shape

Based on Karat's own candidate resources and public candidate reports, expect a 45-60 minute live video interview. The common format is:

1. Brief introduction.
2. Role-specific discussion / knowledge questions.
3. Live coding in Karat Studio or a similar browser-based coding environment.
4. Complexity, edge-case, debugging, and explanation follow-ups.

Your understanding is directionally correct:

```text
Around 20 minutes: experience + frontend / Angular knowledge discussion
Around 40 minutes: live coding
```

Karat's official candidate page describes a 60-minute interview with intro, discussion questions, and about 40 minutes of programming. A Karat support article describes 10-25 minutes of role-specific discussion or code review and 30-45 minutes of coding. So prepare for either split.

## L2 Round Expectation

Checked on May 28, 2026. Public Citi interview reports and current Citi Angular job descriptions suggest L2 is likely one of these:

1. Technical-managerial round with a senior developer, lead, VP, or hiring manager.
2. Project deep-dive round where they validate your real Angular experience.
3. Managerial / behavioral round focused on ownership, communication, pressure, conflict, and fit.
4. Mixed round: 50% Angular / frontend architecture and 50% situational questions.

Prepare for these L2 themes:

- Explain one Angular project end to end: modules/routes, components, services, API flow, auth, state, forms, testing, deployment.
- Defend design decisions: why reactive forms, why service state / NgRx, why lazy loading, why interceptor, why `OnPush`.
- Production quality: testing, code review, performance, accessibility, security, error handling, logging, maintainability.
- Banking mindset: data correctness, secure handling, auditability, compliance, risk awareness, clear escalation.
- Team behavior: ownership, dealing with changing requirements, handling pressure, disagreement, feedback, mentoring, stakeholder communication.
- Leadership signals: independent work, driving a feature, helping juniors, improving process, raising risks early.

Strong L2 positioning:

```text
In L1 I demonstrated technical fundamentals. In L2 I want to show that I can own Angular work in a production team: understand requirements, design clean components and services, integrate APIs safely, test important flows, communicate risks early, and deliver maintainable code in a banking environment where reliability and security matter.
```

## Highest Probability Areas

- JavaScript / TypeScript fundamentals.
- Angular components, lifecycle, routing, guards, forms, services, HTTP interceptors.
- RxJS operators and async data flow.
- State management with RxJS / NgRx.
- REST API integration and microservice frontend patterns.
- HTML, CSS, responsive layout, accessibility.
- Small DSA problems in JavaScript / TypeScript.
- Debugging or extending existing code.
- Time and space complexity explanation.
- Clear communication while coding.

## Your Strong Positioning

```text
I am an Angular-focused frontend engineer who can build enterprise web applications end to end: reusable components, reactive forms, routing, API integration, authentication, state management, performance, accessibility, testing, and production debugging.

For Citi, I understand the frontend is not just UI. It must be reliable, secure, accessible, maintainable, and integrated cleanly with backend microservices in a regulated financial environment.
```
